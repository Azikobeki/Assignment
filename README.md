# Frontend Web Project

## Description

This project is a multi-page frontend website developed using HTML, CSS, and JavaScript. It focuses on building a structured and interactive user interface across several pages, combining consistent design with dynamic elements and animations.

## How to Run

Download or clone the repository and open `Main.html` in a web browser. From there, you can navigate through the different pages of the website.

## Best Viewing Experience

For the intended layout and proportions, open the project in full screen mode. It is also recommended to set the browser zoom level to 75 percent if it is not already, as this ensures that spacing, scaling, and animations appear correctly.

## Pages

* `Main.html` – main landing page
* `Product.html` – product-related content
* `Company.html` – company information
* `Contact.html` – contact page
* `Join.html` – user interaction or sign-up page

## Features

The project includes multiple connected pages with consistent styling, interactive elements, and JavaScript-driven functionality. It demonstrates navigation between pages, structured layouts, and dynamic visual behavior.

## Project Structure

* HTML files – define the structure of each page
* `style.css` – handles all styling and layout
* `script.js` – manages interactivity and animations

## Notes

This project demonstrates the use of core frontend technologies to build a complete multi-page website, focusing on usability, structure, and visual consistency.
